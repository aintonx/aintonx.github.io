# Линза — паспорт визуального языка

Источник истины — два согласованных файла, а не память:
`design/modals-glass.html` (окна и их внутренности) и `design/site-v2.html`
(секции страницы). Если значение здесь и там разошлось — прав референс,
паспорт надо поправить.

Проверять элемент по пяти осям. Нарушение хотя бы одной — элемент не в языке.

## 1. Форма

Ровно четыре формы, промежуточных нет:

| Форма | Радиус | Что |
|---|---|---|
| Капсула | `99px` | все действия и чипы: кнопки, вкладки, метки-подписи, поля-таблетки |
| Круг | `50%` | одиночные значки: `.opt-mark`, `.g-help`, крестик закрытия, номер слота |
| Плитка | `16px` (панель `20–24px`) | блоки-контейнеры, карточки |
| Поле | `13–14px` | ввод, строки-опции, строки-слоты |

Отдельно: вложенные окна-экраны (осциллограф, лента терминала) — `10–12px`,
это законная форма из `site-v2.html`, не путать со старыми прямыми углами.

**Прямые углы 6–10px на органе управления — всегда след старого набора.**

## 2. Материал

```
ПАНЕЛЬ    background: rgba(17,17,21,.46)
          backdrop-filter: blur(26px) saturate(175%)
          border: 1px solid rgba(255,255,255,.10)
          box-shadow: inset 0 1px 0 rgba(255,255,255,.16)

ПЛИТКА    background: rgba(255,255,255,.035)
          border: 1px solid rgba(255,255,255,.09)
          box-shadow: inset 0 1px 0 rgba(255,255,255,.08)
          без blur

ПОЛЕ      background: rgba(255,255,255,.045)
          border: 1px solid rgba(255,255,255,.10)
          box-shadow: inset 0 1px 0 rgba(255,255,255,.06)
          фокус: border rgba(0,200,200,.40) + 0 0 0 3px rgba(0,200,200,.08)

ОПЦИЯ     покой:  rgba(255,255,255,.03) + кромка rgba(255,255,255,.08)
          выбрано: rgba(0,200,200,.06) + кромка rgba(0,200,200,.32)
```

Правило iOS, выстраданное сагой с миганием мембраны: **стекло не анимируется
никогда.** Статичный `backdrop-filter` — можно. Анимировать прозрачность или
фильтр стеклянной панели — нельзя. Внутри стекла двигать только `transform`.

## 3. Типографика

| Роль | Шрифт | Кегль | Трекинг |
|---|---|---|---|
| Метка, подпись поля, чип | mono | 8–9.5px | .12–.15em, uppercase |
| Тело, значение | наборный | 12–13px | 0, интерлиньяж 1.55–1.7 |
| Заголовок, сумма | дисплейный 700 | 18–20px | — |

Длинный текст моноширинным набирать нельзя — читается втрое медленнее.
Моно только для меток и технических значений.

## 4. Цвет-роль

Это ось, которую нарушают чаще всего.

| Цвет | Значение | Где |
|---|---|---|
| Тёплый `#e8c37a` | **главное действие**, цена, итог | `rgba(209,160,74,.09)` фон, `.34` кромка |
| Циан `#4ce0e0` | **выбрано, подтверждено, доступно** | `rgba(0,200,200,.06)` фон, `.32` кромка |
| Красный `#e03030` | **только тревога и запрет** | ошибка, обязательное поле, недоступность |
| Ink | текст | `--ink` → `--ink-4` по убыванию важности |

Красная заливка на кнопке покупки, красная кромка у активного чипа, красный
крестик закрытия — всё это нарушения: пользователь читает красный как «стоп».

## 5. Ритм

8-pt шкала. Внутренний отступ блока всегда меньше внешнего — иначе блоки
слипаются. Токены: `--sp-1..--sp-10`, `--sec-y`, `--head-gap`, `--block-gap`.

## Как проверять

```js
// в консоли страницы: сводка по элементу
const s = getComputedStyle(el);
[s.borderTopLeftRadius, s.backgroundColor, s.borderTopColor,
 s.fontFamily.split(',')[0], s.fontSize, s.letterSpacing, s.color]
```

Что искать в первую очередь:
1. радиус вне четвёрки форм;
2. красный там, где не тревога;
3. моноширинный на тексте длиннее ~140 символов;
4. своя коробка у блока внутри плитки — рамка в рамке;
5. дублирующиеся подписи (артикул трижды, номер шага дважды).
